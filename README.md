# Studio 7 Dance Company — Original Version

The first iteration of the Studio 7 dance company website. This version represents the initial build before a full redesign and revamp was undertaken.

> **Note:** This is the original version. See (studio-7dc.co.za) for the current live version.

---

## About

This was the starting point of a real freelance web development project for Studio 7, a Boksburg-based dance company. The goal was to create an online presence where the company could showcase their instructors, classes, and dance performances.

This version captures the early design decisions and structure before feedback from the client informed the revamped version.

---

## What I learned from this version

- The importance of planning layout and structure before writing code
- How client feedback shapes design decisions in real projects
- Version control as a way to track project evolution over time
- The difference between a first draft and a production-ready website
